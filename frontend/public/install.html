Barb

Explainable phishing triage for Gmail.

Mac

Apple Silicon (M1 or newer). Paste this into Terminal:

curl -fsSL https://secure-inbox.app/install.sh | sh

It installs Barb in Applications and opens it. Run it again to update.

Or download the .zip. macOS blocks it on first open; allow it in System Settings, Privacy & Security, Open Anyway.

iPhone

Open this site in Safari, tap Share, then Add to Home Screen.

Open Barb in the browser
